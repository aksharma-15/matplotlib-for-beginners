> **Objective:** This repository contains an Exploratory Data Analysis (EDA) pipeline developed for popular video game company (assumed a role of a data scientist to make the topics more understandable). The primary objective is to analyze historical video game sales data to identify market trends, perform univariate and bivariate analysis, and determine the optimal genres for future game development. While the role of a data scientist at this video game firm is just for the curiosity of the person checking out this repository and its accompanying jupyer playbook, the main aim of this repository is to teach freshers and carrier switchers the art of plotting graphs and charts with `matplotlib.pyplot` and `seaborn`.

---

## 🎯 Project Objectives

As a Data Scientist focusing on explanatory and exploratory data visualization, this notebook leverages high-level plotting APIs to extract actionable business insights. 

The core visual analysis objectives include:
*   **Custom Styling:** Enhancing default visual aesthetics for stakeholder presentations.
*   **Subplots:** Creating multi-dimensional grid layouts for comparative analysis.
*   **Annotations:** Highlighting key data points and statistical anomalies.
*   **Export Quality:** Ensuring all visual artifacts meet production-grade resolution standards.

---

## 🗂 Dataset Overview

The analysis is performed on the `datasets/final_vg1_final_vg.csv` and `datasets/vgsales.csv` datasets. The data encompasses various data types requiring distinct visualization strategies:

*   **Categorical (Nominal):** Features such as `Platform` and `Genre`.
*   **Categorical (Ordinal):** Features such as release `Year`.
*   **Continuous/Numerical:** Features including `NA_Sales`, `EU_Sales`, `JP_Sales`, `Other_Sales`, `Global_Sales`, and `Rank`.
